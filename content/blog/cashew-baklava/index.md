Baklava, when well made, is an awesome, crunchy, and satisfying experience. This recipe is pretty close to original baklava. I just needed something more fresh for the last course of this meal and decided to go with cashews, dandelion honey, and some lemon juice to brighten up the flavor. Of course, we are also making the dandelion honey ourselves.

This recipe is for a small tray of baklava (20x15 cm).

| Ingredient | Amount | Example | Step |
|------------|--------|---------|------|
| *For the Dandelion Honey:* | | | |
| Dandelion heads | 100% | 100g | Place in water overnight to remove dirt and bugs. Remove the green parts. |
| Water | 350% | 350g | Mix it with the dandelions and bring it to a simmer for 10-15 min. Then leave it overnight to infuse. |
| Sugar | 300% | 300g | Add the sugar to the mixture and simmer it for another 15-30 min or until you reach the right texture. |
| | | | Take about 150g of it and water it down to a runny syrup, then set aside. |
| *For the filling:* | | | |
| Cashews | 200% | 200g | Chop them until you get small chunks around 2-3 mm. It is fine to have a slightly uneven texture. That helps the dish a lot. |
| Lemon zest | 10% | 10g | Mix it with the cashews and set aside. |
| *For the Baklava:* | | | |
| Yufka sheets | | 20 layers à 20x15 cm | |
| Vegetable oil | 60% | 60g | |
| | | | Get a fitting oven-safe pan and place down half of the yufka sheets. Before each layer, brush the sheet with some neutral vegetable oil. |
| | | | After half of the sheets are placed, fill the pan evenly with the cashew-lemon mix. Then add the other layers on top, brushing every layer with oil. Bake it in the oven at 180°C for 20-30 min until golden brown and delicious. |
| | | | Just before it is ready to come out of the oven, heat up the watered-down dandelion honey. As soon as the baklava comes out of the oven, pour the syrup over it to caramelize it in the hot pan. It's up to you how sweet and sticky you want it. |
