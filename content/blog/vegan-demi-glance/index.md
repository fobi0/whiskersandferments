Based on a recipe from the wonderful book "The Art of Food Pairing", I developed a simpler, yet delicious recipe for vegan demi-glance. You can use it on roasts, grilled vegetables, or pair it with tomatoes. It can be prepared in advance, held in a squeeze bottle, and reheated right before dinner.

This is a lighter sauce; you can thicken it by adding a little more tomato purée or a small amount of flour to bind it.

| Ingredient | Amount | Example | Step |
|------------|--------|---------|------|
| Freshly brewed coffee | 100% | 200g | |
| Star anise | 2% | 1 whole | |
| Peppercorns | 5% | 10g | |
| Soy Sauce | 10% | 20g | |
| Tomato purée | 10% | 20g | |
| Onion, chopped | 20% | 40g | |
| | | | Mix all ingredients together and reduce the liquid in a small pot for around 5-10 min. You can reduce it further to create a deeper flavor. Add salt to taste, then pass it through a sieve. |
