This sashimi is made from beetroot. It has an incredibly long shelf life, a texture that is really meaty and chewy, and it tastes amazing. I use it in multiple setups:
- Of course as an addition or replacement for fish in sashimi or sushi. It has a similar texture to raw tuna and is therefore a perfect match for your next vegan sushi party.
- As carpaccio or tartare, it works perfectly as a replacement for beef.
- As cured ham, it is a perfect companion for your next sandwich. You can also cold smoke it a little to get a complex smoke flavor.

In any form, it is a delicious and useful ingredient for a variety of dishes. Due to its high salt content, it will last for a long time in the fridge.

| Ingredient | Amount | Example | Step |
|------------|--------|---------|------|
| Beetroot | 100% | 500g | Brush some oil on it and bake it in the oven for around 45 min at 180°C. The inside needs to be soft and a fork should go in without much resistance. |
| *For the brine:* | | | |
| Soy Sauce | 20% | 100g | |
| Water | 40% | 200g | |
| Salt | 2% | 10g | |
| Kombu | 10% | 50g | |
| Rice Vinegar | 20% | 100g | |
| Sugar | 2% | 10g | |
| | | | Mix all the ingredients until the sugar and salt are dissolved. |
| | | | Cut the beets into pieces. The bigger the pieces, the longer it takes them to dry later. Please note that they will lose about 30% of their volume and weight. |
| | | | Add the pieces to a jar and pour the brine over them. Make sure every beetroot is covered with the brine. Leave it in the fridge for 3-5 days. |
| | | | After the curing process, pour away the liquid (you can use it as a dipping sauce or as a flavor bomb for noodles or stir-fry if you don't want to waste it). Then place the beets on a rack and dry them at 55°C for around 3-7 hours, depending on the size and water content of the beets. The beets should be chewy and dense and still contain some water. |
| | | | Brush the dried beetroots with a neutral oil. This gives them more fattiness and preserves them even better. |
| | | | For plating, slice them up as thin as possible and enjoy the texture and saltiness. |
